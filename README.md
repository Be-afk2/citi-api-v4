# citi-v4

## 📌 Información General

**Nombre del proyecto:** citi-v4  
**Descripción:** API backend desarrollada con NestJS y TypeORM, estructurada como monorepo. Incluye un módulo de gestión de base de datos y un módulo de API REST para conectar aplicaciones web y móviles de turismo. Implementa JWT para autenticación y un sistema de recomendaciones personalizadas basado en etiquetas asignadas a los lugares, adaptándose a los gustos de cada usuario.  
**Propósito:** Permitir la gestión de datos turísticos y ofrecer recomendaciones personalizadas a los usuarios, facilitando la integración con aplicaciones web y móviles.  
**Estado del proyecto:** Mezcla entre desarrollo y prototipo.  

## ⚙️ Tecnologías y dependencias

- **NestJS:** 11.0.7  
- **Dependencias principales:** TypeORM, JWT, dependencias de base de datos  
- **Base de datos:** MySQL  

## 🚀 Uso

**Instalación de dependencias:**  
```bash
npm install
```
**Correr en desarrollo** 
```bash
npm run start:apidev
```
```bash
npm run start:backdev
```
